# FunnyDeaths — Short Summary

FunnyDeaths is a complete modern rebuild of the classic FunnyDeath plugin, rebranded under `com.escapex.funnydeaths` by EscapeX. It replaces the plain vanilla death message with a random, fully configurable funny line from your `config.yml` — including messages tailored to the damage cause (fall, fire, drowning, PvP…) and to the mob that did the deed — plus a small particle effect at the death spot and a 1-tick-delayed broadcast so nothing flickers.

What makes this rebuild different is that **one jar covers everything**: it runs on CraftBukkit, Spigot, Paper, Folia, Purpur, Leaves, Pufferfish, Arclight and any other Bukkit fork, from Minecraft **1.8.9 all the way to 26.3+**, on Java 8 through Java 25, because it is compiled against the 1.8.8 API and resolves every version-specific API (particles, killer lookups, schedulers, entity and damage-cause renames) reflectively at runtime. Compiling the identical source against the 26.3 API is part of the build verification, so future versions are covered too. Drop it in `plugins/`, keep your old config, and use `/fd toggle` and `/fd reload` exactly as before. Optional companion jars for Velocity and Waterfall turn the death message into a network-wide broadcast for servers running behind a proxy.
